Pipeline id `dasiwa-minimax-h3-i2va` ("MiniMax H3 (DaSiWa) - I2V + audio") in `src/lib/video-pipelines.ts`, workflow `workflows/dasiwa-minimax-h3-i2va.json` (flat API-format, 34 nodes). Captured **verbatim** from a Civitai video's embedded ComfyUI prompt (civitai.red/images/140789326, DaSiWa "MythicAlchemy" workflow by Darksidewalker) — added 2026-08-26. Unlike LTX subgraph templates, no graphToPrompt conversion was needed: the WebM's `WORKFLOW`/prompt Matroska tags already carry the executed flat prompt (see [[ltx-subgraph-workflow-conversion]] for the UI-graph case).

- **Injection contract**: MiniMax H3 workflows have NO PrimitiveStringMultiline/LoadImage. `applyVideoParamsToWorkflow` (comfyui.ts) has a `MiniMaxH3Director` branch: `inputs.prompt` ← params.prompt, and the reference image is patched into the first `type:"image"` item of the `timeline_data` JSON string (input-dir filename, same format as LoadImage). No negative prompt (BasicGuider, CFG-less). Censor seams include `DaSiWa_EnhancedVideoCombine`.
- **Model set** (all in `data/model-catalog.json`, tag `minimax-h3`): `diffusion_models/DasiwaMinimaxH3_dasiwaREF2VAHybridV1.safetensors` (int8 19.53GiB, SHA256 71c61492…b7121c — original civitai model 2877206 was DELETED, mirror `huggingface.co/yamanakaaa2015/mymodel`); `text_encoders/qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors` + both VAEs from `Comfy-Org/MiniMax-H3`; `vae_approx/taeh3.safetensors` from `Kijai/MiniMax-H3-TAE`; `loras/MysticXXX_MMH3-V3.safetensors` (only enabled LoRA, strength 0.9 baked in the DaSiWa stack). VAEs load via `vae/MiniMaxH3/` subfolder — captured Windows `\\` paths were converted to `/`.
- **Pod requirements**: ComfyUI ≥ 0.30.0 (native MiniMax H3: `minimax` CLIP type; `comfy-kitchen` INT8 attention ships in core requirements) + `ComfyUI-DaSiWa-Nodes` + KJNodes. `collectRequiredFiles` (video-pipeline-models.ts) parses DaSiWa `stack_data` JSON (enabled slots only) and `ModelPreviewOverrideKJ.tiny_vae`; NODE_PACKS maps `DaSiWa_*`/`MiniMaxH3*` → darksidewalker/ComfyUI-DaSiWa-Nodes.
- **Pod `onechat_ltx25_h100_002`** (podId k632wdpk3ghyhj, H100 80GB, ComfyUI at `/workspace/runpod-slim/ComfyUI`): upgraded v0.26.2→v0.34.0, all models downloaded, DaSiWa + KJ nodes installed. **NVFP4 text encoder on Hopper runs via software dequant** — if it ever errors, swap to `qwen3vl_32b_minimax_h3_int8_convrot` (27GB, same repo). Useful mirror for other H3 quants/turbo LoRAs: `huggingface.co/Kutches/minmax`.
- **Pod has NO network volume — every stop/start resets /workspace to the container image (ComfyUI 0.26.2, no models, no custom nodes)**, surfacing as ComfyUI 400 missing_node_type on MiniMax nodes. Fix: re-run `scripts/setup-minimax-h3-pod.sh` on the pod (idempotent; scp via `ssh -p <mapped 22 port from RunPod API> root@<publicIp>`). Last restore 2026-09-04.
- **RunPod proxy 524 during MiniMax gens (diagnosed 2026-09-10)**: ComfyUI's event loop blocks for minutes while swapping the 34GB bf16 UNET / 32B encoder in and out of VRAM, so any HTTP call through the Cloudflare proxy (~100s limit) can 524 while the generation itself keeps running and succeeds. comfyui.ts now: polling loops treat /history failures as transient (idle timeout still bounds), POST /prompt 524 → poll queue for our client_id instead of resubmitting (blind retries were duplicating generations), uploads retry ×3, HTML proxy error pages are summarized. Completed-but-"failed" clips are recoverable from the pod's /history + output dir (did this for 12 clips on 2026-09-10). Pod-side symptom check: `ssh` in, `curl 127.0.0.1:8188/queue` responds instantly while the proxy 524s.
- **Checkpoint mirror changed 2026-09-04**: the int8 mirror (yamanakaaa2015/mymodel, 19.53GiB, SHA 71c61492…) went private/401. Now using the **bf16 original, 34GB/32GiB, SHA ddd1641d…04c4d from `frauleinpiss/DasiwaH3mirror`** (same DaSiWa REF2VA Hybrid v1) — script + model-catalog updated. Caveat: this Director workflow loads the UNET through TWO UNETLoader branches, so bf16 may pressure VRAM (int8 was 2×19.5GB); if OOM, hunt a smaller quant for this pipeline only. [[minimax-h3-multiref-pipeline]] (single UNETLoader) is unaffected.
