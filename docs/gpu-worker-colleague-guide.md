# (초안) GPU 잠깐 빌려 쓰기 부탁 안내문

> marc가 동료에게 보낼 안내문 초안. 발송 전 IP, 폴더, 일정 확인 필요.

안녕하세요, marc입니다. 캐릭터챗 이미지 생성 품질과 속도를 시험하려고 PC의 그래픽카드를 잠깐 빌리려 합니다.

## 무엇을 하게 되나

- PC에 폴더 하나(`C:\gpu-worker`)를 두고, 켜 두신 동안만 저희 맥에서 그 PC 그래픽카드로 이미지를 생성합니다.
- 켜고 끄는 건 전적으로 직접 정하시면 됩니다. 게임이나 그래픽 작업을 하실 때는 꺼 주세요.
- 디스크 사용량: 프로그램 약 5~8GB, 모델 파일 약 7~15GB. 전부 이 폴더 안에만 저장됩니다.

## 보안

- 사내망(10.202.x.x)에서만 접속할 수 있도록 Windows 방화벽 규칙을 추가합니다. 회사 밖이나 외부 인터넷에서는 접속할 수 없습니다.
- 생성 프로그램은 이 폴더 안의 파일만 읽고 씁니다. 문서나 사진 같은 개인 파일에는 접근하지 않습니다.
- 언제든 `stop-worker.bat`으로 바로 끌 수 있습니다. 완전히 지우려면 `uninstall-worker.bat` 실행 후 폴더를 삭제하면 끝입니다.

## 설치 (처음 한 번)

1. 전달드린 `gpu-worker` 폴더를 `C:\gpu-worker`에 풀어 주세요. 안에 `worker-config.json`이 들어 있습니다.
2. `start-worker.bat`을 더블클릭합니다.
   - 처음에는 프로그램(약 2GB)과 모델을 내려받느라 시간이 걸립니다.
   - 방화벽 규칙 추가 때 관리자 권한을 묻는 창이 한 번 뜹니다. "예"를 눌러 주세요.
   - "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"을 눌러 주세요(인터넷에서 받은 파일이라 뜨는 확인 창입니다).
3. "GPU worker is ON"이 보이면 끝입니다. 창은 닫으셔도 됩니다.

## 평소 사용

| 하고 싶은 것 | 실행 |
| --- | --- |
| 켜기 | `start-worker.bat` |
| 끄기 | `stop-worker.bat` |
| 완전 제거 | `uninstall-worker.bat` 실행 후 폴더 삭제 |

- PC를 재부팅하면 꺼진 상태로 돌아옵니다. 자동으로 켜지지 않습니다.
- 오류가 나면 창을 캡처해서 보내 주세요. `logs` 폴더도 함께 주시면 빨리 볼 수 있습니다.

## 시험 일정

- 1차: 3060 PC 한 대로 속도와 품질 확인 (약 1시간)
- 이후: 켜 두신 시간 동안 두 명이 이미지 생성에 사용

시간 괜찮으실 때 말씀 주시면 맞춰서 진행하겠습니다. 감사합니다.
